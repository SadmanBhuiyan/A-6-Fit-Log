# FitLog

FitLog is a fitness workout library and planning web application. It allows users to browse workouts, save exercises, create a daily workout plan, and keep track of completed workouts through a simple and modern interface.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- DaisyUI
- React Hot Toast

## Key Features

1. **Workout Library**
   - Browse different workouts with details such as equipment, duration, calories, muscle groups, and rating.

2. **Daily Workout Plan**
   - Add workouts to a personal daily plan with a maximum of five workouts.

3. **Saved Workouts**
   - Save workouts for later and easily add them to the daily plan.

4. **Workout Tracking**
   - Mark planned workouts as completed and keep track of your progress.

5. **Workout Sorting**
   - Sort workouts by duration, calories burned, or rating for easier browsing.
